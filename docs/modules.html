Software and commerce

Modules and a storefront

Analysis software ships as digitally signed WebAssembly modules that run the same everywhere. A built-in storefront lets you offer data, modules and services straight from your node.

Open-source astrodynamics

A complete SSA processing baseline, with no proprietary licenses.

Orbit propagation

SGP4/SDP4 for element sets, plus numerical integration for high-precision ephemeris.

Observation association

Correlate radar tracks, optical measurements and RF detections with cataloged objects, or flag new ones.

Orbit determination

Batch least-squares and sequential filters; differential correction refines elements from tracking data.

Conjunction assessment

Screen close approaches, compute collision probability with hard-body-radius screening, and generate CDMs.

Every function is one WebAssembly artifact, executed unchanged by the server, the WasmEdge runtime and the browser: the same bytes and the same numbers everywhere, not a port or a JavaScript approximation.

The storefront

Monetize space data and software with built-in commerce.

  1. Publish a listingA provider publishes one digitally signed listing per module version and stores the encrypted bundle by content ID.
  2. Purchase accessBuyers pay through the storefront with credits, crypto, card, or a free grant.
  3. Grant and fetchThe buyer’s node requests a delivery grant, fetches the encrypted bundle and receives wrapped key material.
  4. Decrypt and runThe key is unwrapped locally, the module is decrypted and loaded, and it runs on the buyer’s machine.

Data products

High-precision ephemeris, proprietary conjunction analysis, historical catalogs, real-time tracking feeds and specialized sensor data.

Software modules

Analysis algorithms, visualization tools, format converters, integration connectors and custom propagators, delivered encrypted.

Services

Work your node performs for others, such as conjunction screening or orbit determination. Listed in the storefront, where anyone can request it.

Payments

Cards, one-time purchases, subscriptions, usage-based billing per record and byte delivered, and enterprise invoicing.

Field-level access control lets you share coarse data openly and sell the precise values. Every buyer gets their own key, so purchases cannot be shared or resold. Core data exchange stays free and open; commerce is opt-in.

Put your data on the network

Only Space Data Standards data is allowed, so every participant can parse and validate it.

Use the SDK

The JavaScript and Go SDKs convert common formats (TLE, CCSDS XML/KVN and more) to SDS FlatBuffers.

AI assistant

An assistant maps your existing schemas to SDS formats and generates the conversion code.

Request a schema

If nothing fits, propose an addition on the SDS repository. Schemas stay backwards compatible.

Step-by-step instructions are in the getting-started guide; module tooling is in the Module SDK.
