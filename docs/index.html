Space Data
Network

Open, peer-to-peer exchange of signed space data. Orbits, catalogs, conjunction warnings and space weather come straight from the people who produce them, and your node checks every record on arrival.

Get started Download

Signed at the source

Every record carries its publisher’s signature and is verified before your node stores it, over encrypted connections with verifiable identities.

Security and identity →

No central server

Nodes find each other over the public IPFS network and trade data directly. A node behind a firewall still works.

How the network works →

Modules and a storefront

Open-source astrodynamics runs as signed WebAssembly, the same file in a browser or on a server. Sell data or modules straight from your node.

Modules and commerce →

Private screening

Encrypted conjunction assessment screens maneuver ephemeris without broadcasting burns or intent to competitors.

Encrypted conjunction assessment →

Combined orbital catalog

One versioned catalog built from every provider, HPOP first. Each orbit keeps its source, its uncertainty status and the rule that selected it.

Docker

Identity and data live in the sdn-data volume.

docker run -d --name sdn --hostname sdn --restart unless-stopped \
  -v sdn-data:/app/data \
  -p 127.0.0.1:5001:5001 -p 4001:4001 -p 4001:4001/udp \
  dockerdigitalarsenal/space-data-network:v1.0.5-beta.70
