Space Data Network

Open, peer-to-peer exchange of signed space data, including orbits and ephemerides, object catalogs, conjunction warnings, maneuver plans, tracking observations, RF spectrum, space weather, launch and reentry events, and more. Records come straight from the people who produce them, and your node checks every one on arrival.

What The Network Does

Signed at the source

Every record carries its publisher’s signature and is verified before your node stores it, over encrypted connections with verifiable identities.

Security and identity →

No central server

Nodes find each other over the public IPFS network and trade data directly. A node behind a firewall still works.

How the network works →

Modules and a storefront

Open-source astrodynamics runs as signed WebAssembly, the same file in a browser or on a server. Sell data or modules straight from your node.

Modules and commerce →

Private screening

Encrypted conjunction assessment screens maneuver ephemeris without broadcasting burns or intent to competitors.

Encrypted conjunction assessment →

Combined orbital catalog

One versioned catalog built from every provider, HPOP first. Each orbit keeps its source, its uncertainty status and the rule that selected it.

SDN Stack

Built On Open Standards

Space Data Standards

The canonical space data schemas (orbits, catalogs, conjunctions, tracking, RF, weather and more) with generated bindings for every major language.

spacedatastandards.org →Apache-2.0

FlatBuffers

Zero-copy binary encoding with schema tooling and runtimes, including flatc compiled to WebAssembly for browsers and servers.

FlatBuffers docs →Apache-2.0

FlatSQL

SQL queries run directly over FlatBuffer records on disk, with no conversion step and no separate database.

FlatSQL docs →PolyForm Noncommercial 1.0.0

Space Data Network

The node, dashboard, desktop app and JavaScript SDK: signed publication, discovery, delivery and the storefront.

Module SDK
