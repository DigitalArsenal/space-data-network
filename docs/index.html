Space Data
Network

Open, peer-to-peer exchange of signed space data. Orbits, catalogs, conjunction warnings and space weather come straight from the people who produce them, and your node checks every record on arrival.

Get started Download Catalog whitepaper

Signed at the source

Every record carries its publisher's signature and is verified before your node stores it. Data uses the open Space Data Standards formats.

No central server

Nodes find each other over the public IPFS network and trade data directly. A node behind a firewall still works.

Modules and a storefront

Analysis modules run in a WebAssembly sandbox, the same file in a browser or on a server. Sell data or modules straight from your node.

Private screening

Encrypted conjunction assessment screens maneuver ephemeris without broadcasting burns or intent to competitors.

Technical whitepaper · September 2026

An attributed, HPOP-first orbital catalog

How SDN combines provider catalogs into one versioned catalog. Every orbit keeps its source, its uncertainty status and the rule that selected it. High-precision numerical propagation (HPOP) is the primary path; SGP4 stays for native GP products and comparison with SOCRATES.

Read the PDF Markdown
  • 13,808Vimpel element rows converted to attributed epoch states, with native IDs and source hashes kept.
  • 6–11 km → 53–70 mWithheld-position RMS after one initial-state refinement, on three four-hour arcs.
  • Every provider keptOriginal products stay as distinct records; the catalog records why one solution was chosen.
  • The results show consistency with provider products, not independent accuracy. The paper states its limits.
