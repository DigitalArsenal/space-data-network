Why it exists

Safety Data Shouldn’t Depend On Who You Know

Today the most accurate orbits sit behind agreements. Most operators screen for collisions with less than the best data available.

Tiered access

The best orbits, and the error bubbles around them, go to whoever holds an agreement.

Private terms

Access is negotiated deal by deal. Nobody outside a deal can see what its data may be used for.

Hidden catalogs

Send your ephemeris in, get warnings back. The catalog behind them can’t be inspected or checked.

Free isn’t open

A free service that collects every operator’s orbits gets better with each one that joins. What it learns stays with its owner.

The answer

One Catalog, Open To Everyone

No sensor network sees everything. The network takes every source, keeps each one digitally signed, and shows its work.

Unlimited sources

Radars, telescopes, star trackers, laser ranging, satellite operators, universities and other nations. Anyone can publish. No contract.

Every orbit attributed

Digitally signed by its producer, original bytes kept, and uncertainty attached whenever the source has it.

Nothing hidden

Each catalog version publishes its inputs and recipe. Anyone can rerun it and get the same answer.

The network

What The Network Does

Digitally signed at the source

Every record carries its publisher’s Ed25519 digital signature, verified before your node stores it, over encrypted connections with verifiable identities.

Security and identity →

No central server

Nodes find each other over the public IPFS network and trade data directly. No single owner can switch the catalog off.

Your data, your terms

Publish free or sell straight from your node. Terms sit in a digitally signed listing everyone can read. Open-source astrodynamics runs as digitally signed WebAssembly.

Who you trust

Trust You Can Measure

Every publisher digitally signs with a key. Adversarial security shows how much that key is worth protecting, and whether it is still safe, by tying it to cryptocurrency anyone can see.

One key, two jobs

The key that digitally signs a node’s records also derives addresses on several blockchains. Identity and value share one key.

Value as a bond

Deposit funds at those addresses. The owner can bond its own key, and anyone who relies on it can add more to raise the stakes.

Attackers prove the point

Whoever steals the private key can take the funds instantly and anonymously, so they will. Funds that stay put mean the key has not been stolen.

Checked every block

Balances are public and update with every block: a live, permissionless signal instead of a certificate authority’s word. Each node sets its own rules for whose data it accepts.

SDN Stack

Built On Open Standards And Software

Space Data Standards

The canonical space data schemas (orbits, catalogs, conjunctions, tracking, RF, weather and more) with generated bindings for every major language.

spacedatastandards.org →Apache-2.0

FlatBuffers

Zero-copy binary encoding with schema tooling and runtimes, including flatc compiled to WebAssembly for browsers and servers.

FlatBuffers docs →Apache-2.0

FlatSQL

SQL queries run directly over FlatBuffer records on disk, with no conversion step and no separate database.

FlatSQL docs →PolyForm Noncommercial 1.0.0

Space Data Network

The node, dashboard, desktop app and JavaScript SDK: digitally signed publication, discovery, delivery and the storefront.

Source on GitHub →MIT

Module SDK

Build, validate, digitally sign and package the WebAssembly modules that SDN nodes and browsers run.
