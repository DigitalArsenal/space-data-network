Why it matters

Data Infrastructure Hasn’t Kept Up With The Growing Space Economy

Every satellite owner-operator needs timely access to vital data, including what is coming close. How well that works comes down to three things: how the data is organized, how fast it moves and whether it can be trusted.

Organization

TodayOrbit data is spread across many websites, each with its own login and its own kind of file.

On the networkOne open standard that any software can read, on one network every source can publish to.

Speed

TodayEveryone downloads the same big files, again and again, every time they change.

On the networkEach update is published once and passed from node to node.

Security and attribution

TodayFiles move from system to system with nothing to prove who made them or that nobody changed them.

On the networkEvery record is digitally signed by its source and checked by every node. Sold data opens only for the buyer.

What the network is

One Shared Catalog, Built From Every Source

No single tracking network sees everything in orbit. The network combines every source into one catalog, keeps each record digitally signed by whoever produced it, and shows how each result was reached.

Any source can contribute

Radars, telescopes, satellite operators, universities and other nations. Anyone can publish, free or for sale.

Every record has a source

Digitally signed by whoever produced it, kept exactly as published, with its margin of error whenever the source gives one.

Results anyone can check

Each version of the catalog lists its inputs and method. Anyone can rerun it and get the same answer.

Censorship resistant

No central server or gatekeeper. Records pass from node to node, so no single party can remove them, alter them unnoticed, or shut a publisher out.

Trust

Knowing Whose Data To Trust

Every publisher signs with a digital key. Adversarial security shows whether that key is still safe by tying it to money anyone can see.

One key, two jobs

The key that signs a node’s records also controls cryptocurrency accounts. Identity and value share one key.

Value as a bond

The owner deposits funds in those accounts, and anyone who relies on the source can add more to raise the stakes.

Attackers prove the point

Whoever steals the private key can take the funds instantly and anonymously, so they will. Funds that stay put mean the key has not been stolen.

Checked continuously

Balances are public and update continuously: a live signal anyone can check, instead of taking a certificate on trust. Each node decides whose data it accepts.

SDN Stack

Built On Open Standards And Software

Space Data Standards

The canonical space data schemas (orbits, catalogs, conjunctions, tracking, RF, weather and more) with generated bindings for every major language.

spacedatastandards.org →Apache-2.0

FlatBuffers

Zero-copy binary encoding with schema tooling and runtimes, including flatc compiled to WebAssembly for browsers and servers.

FlatBuffers docs →Apache-2.0

FlatSQL

SQL queries run directly over FlatBuffer records on disk, with no conversion step and no separate database.

FlatSQL docs →PolyForm Noncommercial 1.0.0

Space Data Network

The node, dashboard, desktop app and JavaScript SDK: digitally signed publication, discovery, delivery and the storefront.

Module SDK

Build, validate, digitally sign and package the WebAssembly modules that SDN nodes and browsers run.
