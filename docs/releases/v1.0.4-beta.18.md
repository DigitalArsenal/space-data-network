# Space Data Network v1.0.4-beta.18

First public build of the FlatBuffer-only node. Self-contained bundles for
macOS (Apple Silicon) and Linux (x86-64), each carrying the node, WasmEdge,
Kubo, the dashboard, the wallet sign-in assets, the updater module and the
fleet update trust roots. Install with the one-liners at
https://spacedatanetwork.org or download an archive from this release; see
docs/INSTALL.md for the operator path.

## What is in it

- **Dashboard with no JSON.** Every screen reads Space Data Standards
  FlatBuffer frames; record rows stream into a browser FlatSQL window that is
  queried locally and cleared when the view changes.
- **Sources workflow.** Origins (CelesTrak and any publisher) with signed
  provenance; per-lane SYNC, EXPORT and ARCHIVE; connectors with politeness
  windows; signed archives listed by manifest CID and re-importable.
- **Subscription retention.** A subscription replaces the lane's previous
  set with each publication by default (`replace-current`); `archive-all`
  keeps and pins every publication. Chosen per subscription in the Store,
  defaulted by `subscriptions.default_retention`.
- **Probes.** `/health`, `/ready` (never waits on a busy store) and
  `/metrics` (operator session).
- **Hardening.** First-admin bootstrap is disarmed once the node's root
  identity is bound; `/ipfs/*` serves only content the node holds; the rate
  limiter no longer trusts forwarding headers from remote peers; auth
  databases are owner-only; a routable admin listener with authentication off
  is refused at start.
- **Recovery.** Readers arriving during an engine rebuild answer 503 with
  Retry-After instead of queueing; failed auto-publications are retried with
  backoff and counted.
- **Installers.** The one-line installers resolve the newest node release,
  never a library tag.

## Standards

Built against Space Data Standards 1.210.0 ($DSS.RETENTION,
$STF.RECOMMENDED_RETENTION; $NDS, $NST, $QRP, $AGR, $ACT, $WXF, $TCT).

## Known limits in this beta

- Kubo is bundled and supervised by the node only when running from the
  bundle; a bare binary still needs a Kubo of your own (`SDN_KUBO_BINARY`
  or `admin.ipfs_api_url`).
- Archives are not announced to the network; keep their manifest CIDs
  (docs/RESTORE.md).
- Publishing a dataset is an API and config workflow; the dashboard wizard
  covers listings only.
- The update feed serves linux/amd64 on the beta channel; other platforms
  update by reinstalling.
- One update-signing root; rotation lands in a later beta.
