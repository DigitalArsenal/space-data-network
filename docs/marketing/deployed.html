Deployed on the Network

What is running on each host, and what does it do?

It depends on the host. host-01 (sdn.spaceaware.io) serves the signed module catalog that apps and nodes install from, and publishes solar-system, star and terrain data. host-02 is the CelesTrak ingest node: it publishes the satellite catalog, element sets, RF bands, space weather and connectivity data. Modules are programs a customer runs; flows are data lanes a host keeps current. Every row was read from the network itself, not typed, and the list is made again on every deploy and every day.
