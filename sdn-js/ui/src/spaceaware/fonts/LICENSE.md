makes **zero external requests** at runtime (strict CSP posture). All three
families are licensed under the **SIL Open Font License, Version 1.1 (OFL-1.1)**,
which permits bundling, redistribution, and embedding. Full license text:
<https://openfontlicense.org> (OFL-1.1).
